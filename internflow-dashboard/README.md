# AI Mock Interview & Candidate Assessment Platform

## 📌 Overview
A role-based web application for AI-powered mock interviews and candidate assessment. Built with React and Bootstrap.

## 🚀 Features

### Candidate Dashboard
- AI resume scoring & ATS analysis
- Mock interview practice sessions
- Performance analytics & progress tracking
- Interview history & feedback

### Recruiter Dashboard
- Candidate talent pool with AI rankings
- Side-by-side candidate comparison
- Custom interview templates
- Real-time session monitoring

### Admin Dashboard
- User & recruiter management
- Platform configuration
- AI model settings
- System health monitoring
- Activity audit logs
