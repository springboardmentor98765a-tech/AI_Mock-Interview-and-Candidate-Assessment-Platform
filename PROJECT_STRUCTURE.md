# Project Structure

- `index.html`: Landing/auth entry.
- `pages/`: Candidate, recruiter, admin, reports.
- `css/style.css`: Shared styles and responsive themes.
- `js/auth.js`: Authentication UI and API integration.
- `js/script.js`: Core dashboard, interview, recruiter, admin logic.
- `js/candidate-advanced.js`: Advanced candidate production modules.
- `js/api-client.js`: Shared API base, auth headers, retries.
- `smarthire-backend/smarthire-backend/src/main/java/com/smarthire/backend/`: Backend services.
- `smarthire-backend/smarthire-backend/src/main/resources/application.properties`: Runtime config.
- `.github/workflows/ci.yml`: CI pipeline.
- `docker-compose.yml`: Multi-service runtime.
